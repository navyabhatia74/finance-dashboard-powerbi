# finance-dashboard-powerbi
## Overview
This Finance Dashboard was built using Power BI to analyze sales performance,profitability trends,business segments, and regional financial insights through interactive visualizations
## Key Insights
-Revenue trend analysis
-Segment-wise sales distribution
-Product profitability comparison
Geographic profit distribution
-Financial KPI tracking 
## Dashboard Features
-KPI Cards
-Interactive slicers
-Revenue trend visualization
-Funnel chart
-Filled map
-Donut and bar charts
## Tools Used
-Power BI
-DAX
-Data Visualization
-Business Analytics
